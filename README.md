# Мия — арабский по книге

Локальное веб-приложение для чтения сканированной книги и практики по материалам,
которые вручную сверены с источником. PDF в проект не копируется: выберите файл
через просмотрщик на странице «Книга». Браузер хранит страницу, закладки и учебный
прогресс локально; для повторного открытия PDF после перезагрузки выберите его снова.
Язык перевода карточек и тестов можно выбрать в настройках: русский или кыргызский.

## Запуск

Из каталога проекта выполните:

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Проверки:

```powershell
npm test
npm run build
npm run lint
npm audit --audit-level=moderate
```

## Учебные данные

Проверенный каталог находится в `src/data/course.ts`; типы и проверки — в
`src/types/course.ts` и `src/lib/course.ts`. Уроки, слова и вопросы должны иметь
проверенную страницу-источник и флаг `verified: true`. Для вопросов с вводом ответа
можно указать только подтверждённые `acceptedAnswers`.

Предоставленный PDF содержит 332 страницы-изображения. В каталог включены вручную
сверенные материалы со страниц 2–6, 9, 11, 13, 16, 19, 20, 24, 26, 28, 30, 33, 35, 38, 40, 41, 43 и 46 PDF;
поле `sourcePage` указывает физическую страницу файла. Словарные таблицы до страницы
30 и примеры урока 16 на страницах 31–32, а также словарные таблицы уроков 17–20 на
страницах 33, 35, 38 и 40 сверены по изображениям оригинала. Страница 41 продолжает
урок 20; на странице 43 начинается урок 21 с таблицей спряжения глагола, а на странице
46 — словарная таблица урока 22.
Остальные OCR-черновики диапазона 7–48 не считаются подтверждённым контентом и не
включены в тесты.

Для локального чернового OCR (PDF не отправляется в сеть) установлен Tesseract.js с
арабской и русской моделями. Например, чтобы распознать страницы 4–10:

```powershell
node tools/extract-book-ocr.mjs --pdf="C:\путь\к\книге.pdf" --from=4 --to=10 --output="C:\путь\к\ocr.jsonl"
```

Каждая запись OCR сохраняется с `status: "needs-review"`. Даже высокая уверенность
распознавания не означает проверку: перед добавлением материала в `src/data/course.ts`
сверьте арабский текст, огласовки и перевод непосредственно со страницей книги.
Файл результатов и сам PDF не следует помещать в публичный каталог приложения.

Кыргызские варианты — дополнительный перевод, подготовленный отдельно от книги;
они не являются цитатами из источника и пока не проверены носителем языка.
Русский перевод книги остаётся доступен в настройках.
страницам 41 и 46 сверены соответственно таблица форм прилагательных урока 21 и
словарная таблица урока 22. Остальные OCR-черновики диапазона 7–48 не считаются
подтверждённым контентом и не включены в тесты.
